# Offline guess dictionary

`english-five-letter.txt` contains the alphabetic five-letter entries from
[dwyl/english-words](https://github.com/dwyl/english-words), `words_alpha.txt`,
downloaded on 2026-10-03. The upstream Unlicense is included here.
The themed answers are also explicitly added to validation in `dictionary.js`.
The dictionary is bundled by Vite, with no runtime network request.
